# База данных музыкального стриминга

## Разрабы
Герасименко Егор (единственный и неповторимый)
Мухлынин Матвей (тот самый матвийко)

## Описание

Данный репозиторий содержит SQL-скрипты для создания схемы и наполнения базы данных сервиса музыкального стриминга. Схема спроектирована с учетом требований Первой нормальной формы (1НФ) для обеспечения атомарности данных и исключения избыточности.

## Структура базы данных

База данных состоит из следующих таблиц:

*   **Roles**: Роли пользователей (например, admin, user).
*   **Users**: Основные аккаунты пользователей.
*   **Artists**: Расширенные профили пользователей, являющихся артистами (связь 1 к 1 с таблицей Users).
*   **Labels**: Музыкальные лейблы (вынесены в отдельную таблицу для соблюдения 1НФ).
*   **Genres**: Музыкальные жанры (вынесены в отдельную таблицу для соблюдения 1НФ).
*   **Tracks**: Музыкальные треки (название, длительность, дата релиза, ссылка на лейбл).
*   **Track_Genres**: Связующая таблица "многие ко многим" для треков и жанров.
*   **Albums**: Музыкальные альбомы (дата выпуска, ссылки на лейбл и артиста).
*   **Album_Tracks**: Связующая таблица "многие ко многим" для альбомов и треков.
*   **Playlists**: Пользовательские плейлисты (название, приватность, описание).
*   **Playlist_Tracks**: Связующая таблица "многие ко многим" для плейлистов и треков.
*   **Listening_History**: История прослушиваний (устройство, длительность, время).
